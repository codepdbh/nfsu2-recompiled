# Проверка на Android-устройстве — 2026-10-07

## Артефакт и устройство

- Приложение: `com.nfsu2.androidevolved`, версия `0.1.0-bootstrap`, отладочный APK ARM64.
- Иконка: точная `ICONO/ICONO.png`, упакованная как `drawable/icono.png`.
- Устройство: Samsung SM-S938B, Android API 36, Adreno 830.
- Версия Vulkan, заявленная физическим устройством: 1.3. Инстанс запрашивает Vulkan 1.1,
  а при инициализации устройства включается только VK_KHR_swapchain, без дополнительных
  фич. Это не проверка на драйвере, ограниченном только Vulkan 1.1.
- Нативная поверхность: 2340 × 1080.
- SHA-256 APK:
  `8d10a7a4a53ba1c9f9bd6400d6660f2d03fb7caeb458700a060b57e59efefdbb`.

## Перенос данных

Создана папка `/storage/emulated/0/nfsu2`, изначально отсутствовавшая. Скопировано 1 262 файла,
1 854 310 887 байт из локальной установки владельца: папки с контентом игры,
оригинальный исполняемый файл, сопутствующие файлы в корне и существующие данные мемкарты.
Исключены установщики DirectX для PC, установщики Support, деинсталляторы и посторонние
скриншоты/иконки из корня. SHA-256 каждого скопированного файла сверен с источником:
все 1 262 совпали, включая ожидаемый хеш SPEED2.EXE.

APK читает напрямую из этой папки; контент игры в него не встроен.
Для будущих переносов можно использовать `scripts/copy_android_data.ps1`; он сохраняет
существующую на устройстве папку мемкарты, а не затирает сохранённый прогресс.

## Границы охвата

Оригинальный исполняемый файл игры рассматривается как данные, а не выполняется. Сгенерированный C,
портированная диспетчеризация Win32/COM, трансляция D3D9, ввод и звук игры
не подключены. Эти результаты не подтверждают геймплей или полноценный рендерер.
В интерфейсе для пользователя прямо указано, что игра ещё не интегрирована.
