# Проверка рантайма 0.3.0 на устройстве — 2026-10-07

Установлен и запущен отладочный APK ARM64 на авторизованном ADB-устройстве
R5GL70TXWMP, Samsung SM-S938B, Android API 36, Adreno 830.

Игра читает файлы владельца из `/storage/emulated/0/nfsu2`.
APK использует предоставленную иконку. Инстанс Vulkan запрашивает API 1.1;
протестированный драйвер заявляет 1.3. Устройство, ограниченное только Vulkan 1.1,
не тестировалось, и дополнительные требования к фичам DXVK по-прежнему актуальны.

Портированный исполняемый файл игры прошёл инициализацию через реальное создание
устройства DXVK D3D9, загрузку и создание встроенных шейдеров, текстуры,
объявления вершин, вершинные/индексные буферы и блокировки ресурсов. Это
не означает успешного рендеринга игровой сцены или геймплея.

Исправлен сбой инициализации на Android, вызванный тем, что DXVK пытался создать
каталог кэша из пустого пути. Опциональное кэширование состояния DXVK на Android отключено,
логирование в файл также отключено. Добавлены запросы процессорной принадлежности (affinity),
которые сообщают об одном виртуальном CPU x86, представленном сериализованным
гостевым рантаймом; невалидные хендлы и маски возвращают ошибки.

Текущая явная граница интеграции:
`dinput8.dll!DirectInput8Create` по гостевому адресу `0x006d7100`.
Игра ещё не дошла до меню. Ввод, звук, остальные Windows API
и полное поведение геймплея/жизненного цикла пока не реализованы.

Доказательства: `work/android-dxvk-device-test.log` и скриншот
`work/android-dxvk-device-test.png` в родительской рабочей директории.
Тест Vulkan на Linux/Xlib доходит до той же границы DirectInput:
`work/android-runtime-surface-host-test.log`.

APK: `build/android/NFSU2-AndroidEvolved-runtime.apk`.
Более ранние отчёты по bootstrap/runtime описывают предыдущие сборки и
не отражают текущий статус интеграции.
